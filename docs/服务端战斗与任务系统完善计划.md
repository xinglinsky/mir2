## 二、对齐C#的关键差异点

### 2.1 战斗系统差异

| 功能 | C#实现 | Rust实现 | 状态 |
|------|--------|----------|------|
| Struck伤害减免 | PlayerObject.Struck | apply_damage_to_player | ✅ 已实现 |
| AC/MAC减伤 | Struck中计算 | apply_damage_to_player | ✅ 已实现 |
| Stat-based反伤 | Reflect% | apply_damage_to_player | ✅ 已实现 |
| AttackBonus | damage += attacker.Stats[Stat.AttackBonus] | apply_damage_to_player_internal | ✅ 已对齐 |
| 伤害处理顺序 | C# HumanObject.Attacked顺序 | apply_damage_to_player_internal | ✅ 已严格对齐 |
| ThornReflect反伤 | BuffType.ThornReflect | handle_combat_buffs_and_counters | ✅ 已对齐（从Buff值读取） |
| CounterAttack | Warrior.CounterAttack | handle_combat_buffs_and_counters | ✅ 已严格对齐（概率/距离/伤害） |
| 装备耐久 | Struck中调用ReduceDurability | apply_equipment_durability_loss | ✅ 已实现 |
| LifeSteal吸血 | BuffType.LifeSteal | handle_combat_buffs_and_counters | ✅ 已对齐（从Buff值读取，仅物理攻击） |
| GatherElement | HumanObject.GatherElement | gather_element | ✅ 已对齐 |
| BrownTime设置 | 玩家攻击玩家/怪物时设置 | apply_damage_to_player_internal | ✅ 已对齐 |
| LevelOffset | ApplyNegativeEffects参数 | apply_negative_effects_with_level_offset | ✅ 已实现 |
| ObjectStruck顺序 | CounterAttackCast后发送 | apply_damage_to_player_internal | ✅ 已对齐 |
| 元素伤害 | Element属性计算 | 无 | ❌ 待实现 |
| MentorDamageRatePercent | 导师伤害加成 | 无 | ⚠️ 需要mentor数据结构 |

### 2.2 任务系统差异

| 功能 | C#实现 | Rust实现 | 差异 |
|------|--------|----------|------|
| 奖励发放 | QuestObject.GiveReward | 无 | complete_quest_for_player不发放奖励 |
| 队伍共享 | QuestObject.ShareQuest | 仅发送包 | 无实际共享逻辑 |
| 选择奖励 | 客户端选择后服务端发放 | 忽略选择 | handle_finish_quest忽略selected_item_index |
| 重复任务 | QuestType.Repeatable | 有标记无处理 | 完成后不可再接 |
