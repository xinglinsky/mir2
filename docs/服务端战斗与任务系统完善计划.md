# 服务端战斗与任务系统完善计划

> 创建时间：2025-01-XX  
> 目标：对齐Rust与C#服务端的战斗和任务系统，确保行为一致性

## 一、当前状态分析

### 1.1 战斗系统现状

#### ✅ 已实现功能
- **基础伤害计算**：`compute_physical_melee_with_crit` 包含暴击判定
- **毒药系统**：完整的毒药应用、叠加规则、抗性判定
- **死亡掉落**：装备/背包物品掉落概率、Spirit套装特殊处理
- **技能伤害**：HalfMoon、CrossHalfMoon等AOE伤害计算
- **玩家攻击判定**：`can_attack_player` 包含地图、安全区、PK状态检查

#### ❌ 缺失功能
1. **防御方伤害处理**（Struck方法）
   - 伤害减免计算（AC/MAC减伤）
   - 反伤机制（ThornReflect等Buff）
   - CounterAttack反击逻辑
   - 装备耐久度损失

2. **高级战斗特性**
   - 吸血（LifeSteal）效果
   - 致命一击（FatalSword）特殊处理
   - 元素属性伤害计算
   - 武器特殊效果（如吸魔）

3. **战斗状态同步**
   - 连击计数器
   - 战斗日志记录
   - 伤害统计

### 1.2 任务系统现状

#### ✅ 已实现功能
- **任务数据结构**：QuestInfo、QuestProgress完整定义
- **进度跟踪**：击杀、收集、Flag任务进度更新
- **任务状态管理**：接受、完成、放弃任务
- **任务列表更新**：客户端显示格式化

#### ❌ 缺失功能
1. **奖励发放系统**（完全缺失）

   - 选择奖励物品处理
   - 信用点奖励发放

2. **任务共享机制**
   - 队伍内任务分享
   - 距离检查（14格范围）
   - 分享冷却时间

3. **高级任务特性**
   - 可重复任务处理
   - 时间限制任务
   - 任务链依赖
   - 动态任务生成

## 二、对齐C#的关键差异点

### 2.1 战斗系统差异

| 功能 | C#实现 | Rust实现 | 差异 |
|------|--------|----------|------|
| Struck伤害减免 | PlayerObject.Struck | 无 | 缺失整个防御处理流程 |
| 反伤机制 | BuffType.ThornReflect | 无 | 无反伤逻辑 |
| CounterAttack | Warrior.CounterAttack | 有框架无触发 | 缺失触发条件 |
| 装备耐久 | Struck中调用ReduceDurability | 无 | 装备不会损耗 |
| 吸血效果 | BuffType.LifeSteal | 无 | 无吸血实现 |

### 2.2 任务系统差异

| 功能 | C#实现 | Rust实现 | 差异 |
|------|--------|----------|------|
| 奖励发放 | QuestObject.GiveReward | 无 | complete_quest_for_player不发放奖励 |
| 队伍共享 | QuestObject.ShareQuest | 仅发送包 | 无实际共享逻辑 |
| 选择奖励 | 客户端选择后服务端发放 | 忽略选择 | handle_finish_quest忽略selected_item_index |
| 重复任务 | QuestType.Repeatable | 有标记无处理 | 完成后不可再接 |
