# Rust 客户端运行指南

## 一、编译客户端

### 1.1 编译 Debug 版本

```powershell
# 在 RustServer 目录下
cd RustServer
cargo build --package crystal-client-bin
```

编译后的可执行文件位于：`RustServer/target/debug/crystal-client-bin.exe`

### 1.2 编译 Release 版本

```powershell
cargo build --release --package crystal-client-bin
```

编译后的可执行文件位于：`RustServer/target/release/crystal-client-bin.exe`

---

## 二、运行模式

客户端支持三种运行模式：

### 2.1 登录/选角 UI 模式（推荐）

这是最完整的客户端模式，包含登录界面、选角界面和基本的游戏场景。

```powershell
# 基本运行（使用默认配置）
cargo run --package crystal-client-bin -- --login-ui

# 指定数据目录
cargo run --package crystal-client-bin -- --login-ui --data-dir "../Build/Client/Debug/Data"

# 指定服务器地址
cargo run --package crystal-client-bin -- --login-ui --server "127.0.0.1:7000"

# 完整参数示例
cargo run --package crystal-client-bin -- --login-ui `
    --data-dir "../Build/Client/Debug/Data" `
    --server "127.0.0.1:7000" `
    --config "config/client.toml"
```

**功能**：
- ✅ 登录界面（账号/密码输入）
- ✅ 选角界面（角色列表、动画）
- ✅ 基本的游戏场景（进入游戏后显示状态信息）
- ✅ 网络连接和协议处理

### 2.2 运行时聊天模式

用于测试网络连接和协议处理，显示简单的聊天界面。

```powershell
# 基本运行
cargo run --package crystal-client-bin

# 指定服务器和账号
cargo run --package crystal-client-bin -- `
    --server "127.0.0.1:7000" `
    --account "test" `
    --password "test123" `
    --start 0

# 使用配置文件
cargo run --package crystal-client-bin -- --config "config/client.toml"
```

**功能**：
- ✅ 网络连接和协议处理
- ✅ 聊天输入/显示
- ✅ 对象状态跟踪（玩家/怪物/NPC）
- ✅ 日志记录

### 2.3 Lib 文件测试模式

用于测试 .Lib 文件的加载和解码。

```powershell
# 测试默认 Lib 文件（Prguse.Lib，索引 1084）
cargo run --package crystal-client-bin -- --lib-test

# 指定 Lib 文件和索引
cargo run --package crystal-client-bin -- --lib-test `
    --lib-path "../Build/Client/Debug/Data/ChrSel.Lib" `
    --lib-index 0
```

**功能**：
- ✅ Lib 文件加载
- ✅ 图片解码和显示
- ✅ 用于调试 Lib 文件格式

## 三、命令行参数

### 3.1 通用参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--config <path>` | 配置文件路径 | `--config "config/client.toml"` |
| `--server <addr>` | 服务器地址（IP:Port） | `--server "127.0.0.1:7000"` |
| `--account <name>` | 账号名称 | `--account "test"` |
| `--password <pwd>` | 密码 | `--password "test123"` |
| `--start <index>` | 角色索引（自动选择角色） | `--start 0` |

### 3.2 登录 UI 模式参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--login-ui` | 启用登录 UI 模式 | `--login-ui` |
| `--data-dir <path>` | 数据目录路径 | `--data-dir "../Build/Client/Debug/Data"` |

### 3.3 Lib 测试模式参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--lib-test` | 启用 Lib 测试模式 | `--lib-test` |
| `--lib-path <path>` | Lib 文件路径 | `--lib-path "Data/ChrSel.Lib"` |
| `--lib-index <n>` | 图片索引（默认：1084） | `--lib-index 0` |

## 四、配置文件

客户端配置文件位于：`RustServer/config/client.toml`

### 4.1 配置文件格式

```toml
# 网络配置
[network]
server_addr = "127.0.0.1:7000"
use_config = false
ip_address = "127.0.0.1"
port = 7000
timeout_ms = 5000

# 图形配置
[graphics]
screen_width = 1024
screen_height = 768
fullscreen = true
borderless = true
top_most = true
mouse_clip = false
font_name = "Arial"
font_size = 8.0
use_mouse_cursors = true
fps_cap = true
max_fps = 100
resolution = 1024
debug_mode = false

# 音频配置
[audio]
volume = 100
music_volume = 100
sound_overlap = 3
sound_clean_minutes = 5

# 游戏配置
[game]
account_id = ""
password = ""
skill_mode = false
skill_bar = true
effect = true
level_effect = true
drop_view = true
name_view = true
hp_view = true
transparent_chat = false
mode_view = false
dura_view = false
display_damage = true
target_dead = false
highlight_target = true
expanded_buff_window = true
expanded_hero_buff_window = true
display_body_name = false
new_move = false
skillbar_location = [[0, 0], [216, 0]]

# 聊天配置
[chat]
show_normal_chat = true
show_yell_chat = true
show_whisper_chat = true
show_lover_chat = true
show_mentor_chat = true
show_group_chat = true
show_guild_chat = true

# 过滤器配置
[filter]
filter_normal_chat = false
filter_whisper_chat = false
filter_shout_chat = false
filter_system_chat = false
filter_lover_chat = false
filter_mentor_chat = false
filter_group_chat = false
filter_guild_chat = false

# 日志配置
[logs]
log_errors = true
log_chat = true
remaining_error_logs = 100

# 账号信息（可选，用于自动登录）
account = "test"
character_index = 0
```

### 4.2 配置文件位置

- **默认路径**：`config/client.toml`（相对于可执行文件）
- **自定义路径**：使用 `--config` 参数指定

## 五、快速开始

### 5.1 首次运行

1. **确保服务端已启动**
   ```powershell
   # 在另一个终端启动服务端
   cd RustServer
   cargo run --package crystal-server-bin
   ```

2. **准备数据文件**
   - 确保 `../Build/Client/Debug/Data/` 目录存在
   - 包含必要的 .Lib 文件（ChrSel.Lib, Prguse.Lib, Title.Lib 等）

3. **运行客户端（登录 UI 模式）**
   ```powershell
   cd RustServer
   cargo run --package crystal-client-bin -- --login-ui --data-dir "../Build/Client/Debug/Data"
   ```

### 5.2 使用已编译的可执行文件

```powershell
# Debug 版本
.\target\debug\crystal-client-bin.exe --login-ui --data-dir "../Build/Client/Debug/Data"

# Release 版本
.\target\release\crystal-client-bin.exe --login-ui --data-dir "../Build/Client/Debug/Data"
```

## 六、常见问题

### 6.1 找不到数据文件

**错误**：`load ChrSel failed: No such file or directory`

**解决**：
- 检查 `--data-dir` 参数是否正确
- 确保数据目录包含必要的 .Lib 文件
- 默认数据目录：`../Build/Client/Debug/Data`

### 6.2 无法连接到服务器

**错误**：`connect error: Connection refused`

**解决**：
- 确保服务端已启动
- 检查服务器地址是否正确（默认：`127.0.0.1:7000`）
- 检查防火墙设置

### 6.3 窗口无法显示

**错误**：窗口不显示或黑屏

**解决**：
- 检查 Bevy 和显卡驱动是否正常
- 尝试使用 `--release` 模式编译
- 检查日志输出

### 6.4 配置文件格式错误

**错误**：`InvalidData` 或 TOML 解析错误

**解决**：
- 检查 TOML 文件格式是否正确
- 删除配置文件让程序使用默认配置
- 查看配置文件示例

## 七、开发模式

### 7.1 使用 cargo run（推荐）

```powershell
# 自动编译并运行
cargo run --package crystal-client-bin -- --login-ui
```

### 7.2 使用 cargo build + 直接运行

```powershell
# 先编译
cargo build --package crystal-client-bin

# 再运行
.\target\debug\crystal-client-bin.exe --login-ui
```

```powershell

cargo install cargo-watch

# 监听文件变化并自动重新编译运行
cargo watch -x "run --package crystal-client-bin -- --login-ui"
```
