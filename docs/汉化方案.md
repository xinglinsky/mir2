# 传奇2项目汉化方案

## 一、项目分析

### 1.1 项目结构
- **客户端**：`Client/` - C# WinForms游戏客户端
- **服务端**：`Server/` - C# 游戏服务端
- **共享库**：`Shared/` - 包含语言系统 `Language.cs`

### 1.2 现有语言系统
项目已实现语言本地化系统：
- **语言文件位置**：
  - 客户端：`.\Language.ini`（客户端运行目录）
  - 服务端：`ConfigPath\Language.ini`（服务端配置目录）
- **语言系统**：`Shared/Language.cs` 使用INI文件存储多语言文本
- **加载方式**：
  - 客户端：`GameLanguage.LoadClientLanguage(@".\Language.ini")`
  - 服务端：`GameLanguage.LoadServerLanguage(Path.Combine(ConfigPath, "Language.ini"))`

## 二、汉化方案设计

### 2.1 设计原则
1. **最小改动**：充分利用现有语言系统，避免大规模重构
2. **客户端优先**：先完成客户端汉化，再处理服务端
3. **向后兼容**：保持原有英文文本作为默认值
4. **易于维护**：所有文本集中在语言系统中管理

### 2.2 实施步骤

#### 阶段一：扩展语言系统（客户端）
1. 在 `Shared/Language.cs` 中添加新的语言键值对
2. 更新 `LoadClientLanguage` 和 `SaveClientLanguage` 方法
3. 将硬编码文本替换为语言系统调用

#### 阶段二：创建中文语言文件（客户端）
1. 创建 `Language_CN.ini` 或直接修改 `Language.ini`
2. 将所有客户端文本翻译为中文
3. 测试客户端显示效果

#### 阶段三：服务端汉化
1. 更新服务端语言系统（如需要）
2. 创建服务端中文语言文件
3. 测试服务端消息显示

### 2.3 技术实现

#### 2.3.1 语言键值命名规范
- 使用描述性名称：`Skill_NoSuitableWeapon`
- 分组前缀：`UI_`, `Chat_`, `Item_`, `Skill_`, `System_`
- 保持与现有命名风格一致

#### 2.3.2 代码修改示例
**修改前：**
```csharp
ChatDialog.ReceiveChat("You must be wearing a suitable weapon to perform this skill", ChatType.System);
```

**修改后：**
```csharp
ChatDialog.ReceiveChat(GameLanguage.Skill_NoSuitableWeapon, ChatType.System);
```

## 八、中文语言文件创建说明

### 8.1 文件格式
语言文件使用INI格式：
```
[Language]
Key=Value
```

### 8.2 创建方法
1. **自动生成**：运行客户端程序，会自动生成包含所有键值的 `Language.ini` 文件（英文版本）
2. **手动翻译**：将生成的 `Language.ini` 文件中的英文值替换为中文
3. **UTF-8编码**：确保文件使用UTF-8编码保存，以正确显示中文

### 8.3 主要翻译项（示例）
- 宠物模式：`[宠物: 攻击并移动]`
- 攻击模式：`[模式: 和平]`
- UI界面：`背包 ({0})`、`角色 ({0})`、`技能 ({0})`
- 提示信息：`您确定要退出传奇2吗？`
- 物品类型：`武器`、`盔甲`、`头盔`
- 属性显示：`DC + {0}~{1}`、`耐久度`、`重量`
- 系统消息：`您必须装备合适的武器才能使用此技能`
- 组队消息：`您已离开队伍。`、`{0} 已加入队伍。`
