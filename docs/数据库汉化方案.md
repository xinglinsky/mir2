## 二、汉化方案设计

### 2.1 方案选择

#### 方案A：扩展 Language 系统（推荐）✅
**优点**：
- 不修改数据库结构，保持兼容性
- 支持多语言切换
- 易于维护和更新（只需更新CSV/INI文件，无需重新编译）
- 不影响现有的游戏逻辑（名称作为ID）
- **高性能**：使用字典（Dictionary）实现O(1)查找，性能优异
- **架构一致**：与现有INI文件加载机制完全一致
- **动态扩展**：新增数据库条目无需修改代码

**缺点**：
- 需要修改客户端和服务端的显示逻辑
- 需要建立名称映射表

**实施方式**：
1. 在 `Language` 系统中添加字典（Dictionary）存储翻译映射
2. 通过INI文件加载翻译数据（与现有机制一致）
3. 提供辅助方法（GetMonsterName、GetItemName等）获取翻译名称
4. 修改客户端显示逻辑，使用语言系统获取显示名称
5. 保持数据库中的原始英文名作为唯一标识符

#### 方案B：直接修改数据库内容（不推荐）❌
**优点**：
- 实施简单，直接修改名称即可

**缺点**：
- 破坏性修改，无法回退
- 可能导致脚本、掉落配置等关联数据失效
- 不支持多语言
- 中文名称作为标识符可能引发编码问题

### 2.2 推荐方案：分层翻译系统

#### 架构设计
```
┌─────────────────────────────────────────┐
│         客户端 / 服务端                   │
├─────────────────────────────────────────┤
│  显示层（使用翻译后的名称）                │
│  GameLanguage.GetMonsterName(id)         │
│  GameLanguage.GetItemName(id)            │
│  GameLanguage.GetMagicName(id)           │
├─────────────────────────────────────────┤
│  语言映射层（Dictionary + INI加载）       │
│  _monsterNames["ChickenMonster"] = "小鸡怪"│
│  _itemNames["GoldOre"] = "金矿"          │
│  _magicNames["Fencing"] = "剑术"         │
│  （从 Language.ini 动态加载）             │
├─────────────────────────────────────────┤
│  数据层（保持英文ID不变）                 │
│  MonsterInfo.Name = "ChickenMonster"     │
│  ItemInfo.Name = "GoldOre"               │
│  MagicInfo.Name = "Fencing"              │
└─────────────────────────────────────────┘
```

### 阶段一：扩展 Language 系统

#### 步骤1：扩展 Language.cs
在 `Shared/Language.cs` 中添加字典和辅助方法：

```csharp
// 在 GameLanguage 类中添加：

// ===== 数据库翻译字典 =====
private static Dictionary<string, string> _monsterNames = new Dictionary<string, string>();
private static Dictionary<string, string> _itemNames = new Dictionary<string, string>();
private static Dictionary<string, string> _magicNames = new Dictionary<string, string>();
private static Dictionary<string, string> _questNames = new Dictionary<string, string>();
private static Dictionary<string, string> _npcNames = new Dictionary<string, string>();

// ===== 辅助方法：根据ID获取翻译名称（O(1)查找，高性能）=====
public static string GetMonsterName(string id)
{
    // 先尝试直接查找
    if (_monsterNames.TryGetValue(id, out var name))
        return name;
    
    // 如果找不到，尝试使用FriendlyName（去除数字和方括号）
    var friendlyId = Regex.Replace(id, @"\d+$", string.Empty);
    friendlyId = Regex.Replace(friendlyId, @"\[[^]]*\]", string.Empty);
    
    if (friendlyId != id && _monsterNames.TryGetValue(friendlyId, out name))
        return name;
    
    // 如果都找不到，返回原始ID
    return id;
}

public static string GetItemName(string id)
{
    // 先尝试直接查找
    if (_itemNames.TryGetValue(id, out var name))
        return name;
    
    // 如果找不到，尝试使用FriendlyName（去除数字和方括号）
    var friendlyId = Regex.Replace(id, @"\d+$", string.Empty);
    friendlyId = Regex.Replace(friendlyId, @"\[[^]]*\]", string.Empty);
    
    if (friendlyId != id && _itemNames.TryGetValue(friendlyId, out name))
        return name;
    
    // 如果都找不到，返回原始ID
    return id;
}

public static string GetMagicName(string id)
{
    return _magicNames.TryGetValue(id, out var name) ? name : id;
}

public static string GetQuestName(string id)
{
    return _questNames.TryGetValue(id, out var name) ? name : id;
}

public static string GetNPCName(string id)
{
    return _npcNames.TryGetValue(id, out var name) ? name : id;
}

// ===== 从INI文件加载数据库翻译 =====
private static void LoadDatabaseTranslations(string iniPath)
{
    _monsterNames.Clear();
    _itemNames.Clear();
    _magicNames.Clear();
    _questNames.Clear();
    _npcNames.Clear();
    
    if (string.IsNullOrEmpty(iniPath) || !File.Exists(iniPath))
        return;
    
    var lines = File.ReadAllLines(iniPath);
    bool inLanguageSection = false;
    
    foreach (var line in lines)
    {
        var trimmed = line.Trim();
        
        // 跳过空行和注释
        if (string.IsNullOrEmpty(trimmed) || trimmed.StartsWith(";") || trimmed.StartsWith("#"))
            continue;
        
        // 检测节名
        if (trimmed == "[Language]")
        {
            inLanguageSection = true;
            continue;
        }
        
        if (trimmed.StartsWith("[") && trimmed.EndsWith("]"))
        {
            inLanguageSection = false;
            continue;
        }
        
        if (!inLanguageSection) continue;
        
        // 解析键值对
        var equalIndex = trimmed.IndexOf('=');
        if (equalIndex <= 0) continue;
        
        var key = trimmed.Substring(0, equalIndex).Trim();
        var value = trimmed.Substring(equalIndex + 1).Trim();
        
        // 根据前缀分类加载
        if (key.StartsWith("Monster_"))
        {
            var id = key.Substring(8); // 去掉 "Monster_" 前缀
            _monsterNames[id] = value;
        }
        else if (key.StartsWith("Item_"))
        {
            var id = key.Substring(5); // 去掉 "Item_" 前缀
            _itemNames[id] = value;
        }
        else if (key.StartsWith("Magic_"))
        {
            var id = key.Substring(6); // 去掉 "Magic_" 前缀
            _magicNames[id] = value;
        }
        else if (key.StartsWith("Quest_"))
        {
            var id = key.Substring(6); // 去掉 "Quest_" 前缀
            _questNames[id] = value;
        }
        else if (key.StartsWith("NPC_"))
        {
            var id = key.Substring(4); // 去掉 "NPC_" 前缀
            _npcNames[id] = value;
        }
    }
}

// 在 LoadClientLanguage 方法中，在创建 reader 之后添加：
public static void LoadClientLanguage(string languageIniPath)
{
    if (!File.Exists(languageIniPath))
    {
        SaveClientLanguage(languageIniPath);
        return;
    }

    InIReader reader = new InIReader(languageIniPath);
    // ... 现有的加载代码 ...
    
    // 在方法末尾添加：
    LoadDatabaseTranslations(languageIniPath);
}

// 在 LoadServerLanguage 方法中，在创建 reader 之后添加：
public static void LoadServerLanguage(string languageIniPath)
{
    if (!File.Exists(languageIniPath))
    {
        SaveServerLanguage(languageIniPath);
        return;
    }
    
    InIReader reader = new InIReader(languageIniPath);
    // ... 现有的加载代码 ...
    
    // 在方法末尾添加：
    LoadDatabaseTranslations(languageIniPath);
}
```

**注意**：
- 代码示例直接读取INI文件，避免使用反射，性能更好
- 也可以选择在 `InIReader` 中添加 `GetAllKeys` 方法，然后使用 `reader.GetAllKeys("Language")` 获取所有键
- 加载时机：在 `LoadClientLanguage` 和 `LoadServerLanguage` 方法的末尾调用，确保所有翻译都已加载

## 七、注意事项

### 7.1 命名规范
- **键名格式**：`类型_英文ID`
  - 怪物：`Monster_ChickenMonster`
  - 物品：`Item_GoldOre`
  - 技能：`Magic_Fencing`
  - 任务：`Quest_Tutorial`

- **英文ID保持不变**：数据库中的 Name 字段必须保持原始英文，作为唯一标识符

### 7.2 兼容性
- **向后兼容**：如果语言文件中找不到翻译，返回原始英文名称
- **默认语言**：英文作为默认语言，中文作为可选语言

### 7.3 性能考虑
- **字典查找**：使用 `Dictionary<string, string>` 实现O(1)查找，性能优异
- **一次性加载**：在启动时从INI文件加载所有翻译到内存，运行时无需IO操作
- **FriendlyName支持**：自动处理带编号的物品/怪物名称（如 "GoldOre1" → "GoldOre"）
- **向后兼容**：找不到翻译时返回原始ID，不影响游戏运行

### 7.4 维护性
- **集中管理**：所有翻译集中在 languages.csv 中
- **版本控制**：翻译文件纳入 Git 管理
- **注释说明**：重要的翻译添加注释说明用途

## 十一、总结

本方案通过扩展现有的 Language 系统来实现数据库内容的汉化，采用**字典（Dictionary）+ INI文件**的架构，具有以下优势：

✅ **非侵入性**：不修改数据库结构和游戏逻辑  
✅ **高性能**：使用字典实现O(1)查找，性能优异  
✅ **可维护性**：集中管理所有翻译内容，只需更新CSV/INI文件，无需重新编译  
✅ **架构一致**：与现有INI文件加载机制完全一致  
✅ **动态扩展**：新增数据库条目无需修改代码，只需更新翻译文件  
✅ **可扩展性**：易于支持多语言  
✅ **向后兼容**：保持现有功能不受影响，找不到翻译时返回原始ID
